## 3. Active State & Completed Stability Audit

- **Current Status:** Completed comprehensive evidence-based stability audit documented in `AETHER_AUDIT.md`. No application code was modified.
- **Key Confirmed Findings:**
  1. *Unanchored Transport Playhead:* Playback start offset and master timer rely on raw `audioCtx.currentTime`, causing clock jumps on Play after pause/stop.
  2. *Non-Atomic Save Dialog:* `save_project_dialog` in `lib.rs` writes directly with `std::fs::write` rather than calling `project_write::replace_project`.
  3. *Missing Wasm in Build Command:* `tauri.conf.json` build command omits `dsp-wasm/` when bundling `dist/`.
  4. *All-or-Nothing Project Load:* `prepareSession()` aborts the entire project import if a single file is missing or fails decoding.
  5. *Redundant Base64 Serialization:* Audio data is serialized twice in projects, downsampling original buffers on reload.
- **Immediate Next Steps (Ordered Repair Plan):**
  1. Fix the transport playhead anchoring in `desktop/index.html` to decouple playback from raw `audioCtx.currentTime`.
  2. Wire `save_project_dialog` in `desktop/src-tauri/src/lib.rs` to use `project_write::replace_project`.
  3. Update `beforeBuildCommand` in `desktop/src-tauri/tauri.conf.json` to include `dsp-wasm`.
  4. Implement scheduler, snapshots, or transition features once the baseline repair plan is complete.
